# StacyBot-Impuls — восстановленная стратегия (кандидат на интеграцию в Aura)

**TL;DR.** Сторонний обфусцированный MT4-эксперт `stacybot-impuls.obf.ex4` (исходник утерян при атаке) реверс-извлечён до **спецификации + чистого эквивалентного `.mq4`**. Это **трендовый trailing-scalper на XAUUSD M30**: на открытии каждого бара берёт направление по EMA(9) (цена выше → buy, ниже → sell), открывает фикс-лот с широким SL и близким TP, дальше агрессивно подтягивает стоп. Без сетки, без мартингейла, до 2 позиций (Long&Short). Винрейт ~98%, profit factor ~2.4 на апрель–июнь 2026. Дословный авторский код невосстановим (терминал хранит только байткод) — восстановлена **точная поведенческая спецификация**, по ней написан собственный `.mq4`. Следующий шаг — внедрение логики в Aura как (предположительно) нового `strategy_type`.

> Эта страница — **дизайн/контекст-документ** восстановленной стратегии перед её внедрением в Aura. Артефакты реверса (отчёты Тестера, трасса Frida, котировки, скрипты подбора, итоговый `.mq4`, спецификация `spec/`) живут в проекте `stacybot-recovery/` (вне репозитория Aura). ### Доказанные факты (НЕ переоткрывать)
1. Фикс-лот обнуляет счёт вне режима 2025-26 (5/9 лет 2018→2026 убыточны).
2. **Риск-% сайзинг = выживание** (v3: 2018→2026 +266% / сквозная DD 23% / переживает все режимы). Это ЯДРО.
3. Винрейт — мусорная метрика (90–98% даже в blow-up годы).
4. **Эджа во входе НЕТ** — фильтры входа (v2 ATR, v4 HTF) не помогают, только режут.
5. ATR-адаптивные уровни (v5) — катастрофа; стратегия любит **ФИКС широкий стоп**.
6. SL — второй рычаг плеча (дублирует RiskPercent); не оптимизировать в максимум (SL=5 → DD 84%).
7. **M30 — родной ТФ**; мульти-ТФ только пер-ТФ ФИКС-пресеты (не ATR), полоса ~M15–H1.
8. **🆕 Трейл (2026-06-15):** оригинал переносит SL в безубыток при **+0.50** (наблюдение live: +$10 на 0.20 лота), наш был +0.30 → выбивался рано. **Двухстадийный трейл (v6): держать широкий стоп → безубыток при `BeTrigger=0.50` → тесный трейл (gap 0.30).** При 0.50 профиль совпал с оригиналом (винрейт 97.9% ровно, ср.выигрыш 33 vs 34, PF 2.2). ⚠️ Прежний вывод «разница = фильтр входа» был НЕВЕРЕН — главным был трейл.

## Происхождение и метод восстановления

Исходный `.mq4` потерян при хакерской атаке; остался только `stacybot-impuls.obf.ex4` (новый формат MT4 build 600+, тело зашифровано, энтропия ≈7.93, обфускация). Прямая декомпиляция невозможна. Восстановление шло по поведению (динамически), а не статикой:

1. **Отчёт Стратегического тестера** (XAUUSD M30, 1384 сделки) → входные параметры, SL/TP, лот, профиль и тайминг сделок, трейлинг.
2. **Трасса Frida** на `terminal.exe` (хуки экспортируемых Win32 API: CreateFile/Network/Registry/DLL) → **доказала отсутствие кастом-индикаторов** (все индикаторы — стартовое сканирование папки) и **отсутствие сетевой активности эксперта** (вся сеть = сам терминал RoboForex). Важно: `iMA/iCustom/OrderSend` НЕ экспортируются (байткод во внутреннем интерпретаторе), поэтому хуки по имени их не видят — отсюда двухъярусная схема трассы.
3. **Офлайн-подбор** правила направления: на 65000 баров XAUUSD M30 перебор period/price/method средней → максимум совпадения на **EMA(9) close** (92.3%; остаток — погрешность EMA у самой линии + рассинхрон офлайн-котировок с тестером).

## Восстановленная спецификация

### Входные параметры
- **Единственный внешний параметр оригинала: `Lots = 0.3`.** Всё остальное (уровни, трейл, правило входа) зашито в код как константы. В нашем `.mq4` они вынесены в параметры (стратегия теперь правится).

### Логика входа
```
На открытии каждого M30-бара:
  ema = EMA(9, close, shift=1)
  направление = (close[1] > ema) ? BUY : SELL
  открыть рыночный ордер в направлении, если позиций в эту сторону == 0 и всего < 2
  лот = Lots (фикс), SL = вход ∓ 25.00, TP = вход ± 6.00
```
- Круглосуточно, без фильтра сессии/спреда (не наблюдалось).

### Логика выхода / сопровождения
- Стартовый SL широкий (25.00), TP близкий (6.00). Закрытие **почти всегда по трейлинг-стопу** (1378 из 1384; по TP лишь 6 раз).
- Трейлинг: как только в плюсе → SL к ≈ безубытку; далее тянется за ценой шагом **~0.30**; TP не двигается. Измеренный зазор «пик→выход» ≈ 5.25 (в `.mq4` воспроизведён, совпал 5.30).

### Управление капиталом
- Фикс-лот `Lots`. **Сетки/мартингейла НЕТ.** До 2 позиций одновременно (Long&Short / хедж; в оригинале 106 из 1384 входов — встречные).

### Числовые константы (XAUUSD, 2-знач. котировка, point=0.01)
| Значение | Смысл |
|---|---|
| 25.00 | StopLoss-дистанция (~2500 пунктов) |
| 6.00 | TakeProfit-дистанция (~600 пунктов) |
| ~0.30 | шаг трейлинг-стопа (~30 пунктов) |
| 9 | период EMA направления |

> ⚠️ Единицы зависят от digits брокера. В коде выражать через `Point`/`Digits`, не хардкодить цену.

## Оценка качества торгового подхода (вердикт специалиста по алготрейдингу, 2026-06-14)

> Это оценка **качества самой стратегии как способа торговать**, а не качества реверса. Цифры — из отчёта Тестера оригинала (`trace/StrategyTesterold.htm`: XAUUSD M30, апр–июн 2026, депо 10000, спред 10, 1384 сделки).

### Профиль доходности — отрицательная асимметрия (negative skew)
| Метрика | Значение |
|---|---|
| Винрейт | 97.9% (1355 из 1384) |
| Средний выигрыш | **+$34.37** |
| Средний проигрыш | **−$676.32** |
| Соотношение убыток : выигрыш | **≈ 20 : 1 против** |
| TP (+6.00) реально достигнут | **6 раз из 1384** |
| Макс. просадка | 2516 (7.32%) / относительная 14.28% |
| Макс. серия убытков в выборке | 2 (−1500) |
| Profit factor / recovery factor | 2.37 / ~10.7 |

Классический **«сбор монеток перед катком»**: много крошечных плюсов, редкие огромные минусы. Реальная цель сделки — не TP 6.00, а трейлинг, фиксирующий ~$34; полная ошибка стоит −$750 (−25.00 × 30 oz при 0.3 лота).

### Откуда берутся 98% побед — это эффект ВЫХОДА, а не входа
Высокий винрейт **создаётся логикой выхода** (перенос SL в безубыток при первом плюсовом тике), а не предсказательной силой входа. Лонги и шорты выигрывают одинаково ~98% при том, что направление — почти случайное «цена vs EMA(9)». Диагностический признак: edge сидит в сопровождении, а не в сигнале.

### Точка безубытка по винрейту — стратегия живёт у самой кромки
При средних +$34.37 / −$676.32 безубыточный винрейт:
> p × 34.37 = (1−p) × 676.32 → **p ≈ 95.2%**

Стратегия работает на **97.9%** — запас всего **~2.7 пп над линией разорения**. Любое устойчивое ухудшение винрейта (смена режима золота, более широкий спред у другого брокера, проскальзывание на стопе) быстро уводит в минус. Конструкция **хрупкая по своей природе**.

### Что объективно хорошо (это НЕ скам-EA)
- **Убыток ограничен**: жёсткий стоп 25.00, худший случай на сделку известен (~$750) и не растёт. Принципиально безопаснее грид-/мартингейл-ботов.
- **Нет усреднения, сетки и прогрессии лота** — риск на сделку константен и прозрачен.
- **Трендовое выравнивание + ≤2 позиций** — не пирамидится.
- **Выборка 1384 сделки** статистически значима: внутри-выборочный edge реален.

### Серьёзные риски (что прячет бэктест)
1. **Окно 2.5 мес — один режим.** Нет ковид-обвала, новостных гэпов, шоков масштаба 2020/2022. Вся опасность negative-skew — в **кластеризации** редких −25 стопов, которой за окно просто не случилось (макс. серия = 2).
2. **90% modelling quality + потиковый трейл = оптимистичный винрейт.** Стратегия с переносом-в-безубыток критически зависит от внутрибарового пути цены — именно его интерполяция из M1 воспроизводит хуже всего. На реальных тиках 98% почти наверняка ниже.
3. **Микро-прибыль уязвима к издержкам.** Средний выигрыш всего $34, вход каждые 30 мин круглосуточно. Плавающий спред золота в новости (0.50+), проскальзывание, **своп за 24/7-удержание** легко съедают тонкую прибыль. Тест на фикс-спреде 10 без комиссии/свопа — тепличный.
4. **Проскальзывание на катастрофическом стопе.** Худшая сделка уже −768 против номинала −750 (стоп проскользнул). −25 срабатывает на быстром движении — там реальный убыток хуже номинала и бьёт прямо по тонкому запасу винрейта.
5. **Фикс-лот без риск-менеджмента от капитала.** −$750 = 7.5% депо $10k на сделку; до 2 встречных позиций = −$1500 за вилку (наблюдаемая серия). На меньшем счёте опасно.

### Вердикт: 3/5 — «рабочая, но хрупкая»
Грамотно сконструированный трейлинг-скальпер с ограниченным убытком (не разводка), но с принципиально **отрицательно-асимметричным** профилем, держащийся всего ~2.7 пп над точкой разорения и доказанный лишь на коротком, вероятно благоприятном отрезке золота с оптимистичным моделированием. Гладкая эквити (228 побед подряд) обманчива — она такая ровно до дня, когда редкие большие убытки впервые сходятся в кучу.

**Чтобы такой подход можно было нести в продакшн / продавать — обязательно:**
- Walk-forward / out-of-sample на 3–5 лет (включая 2020, 2022–2023 — реальная волатильность золота).
- Monte-Carlo на перестановках сделок → реалистичная макс. просадка и риск разорения с учётом skew (наблюдаемые 7% — лучший, не типичный сценарий).
- Форвард-тест на реальном демо с плавающим спредом → фактическое проскальзывание на −25 стопе и качество трейл-филлов.
- **Риск-% сайзинг вместо фикс-лота** + фильтр спреда/новостей перед входом + учёт свопа.

### Импликации для внедрения в Aura
Если внедрять (см. ниже): **не продавать «98% винрейт» как фичу** — это маркетинговая ловушка negative-skew. Обязательно поверх восстановленной логики навесить из арсенала Aura **equity-защиту, риск-% `lot_type`, `spread_buffer`/news-guard**. Сама сигнальная модель слабее, чем кажется по эквити; ценность — в трейле, который у Aura уже есть ([[adr-002-trail-rework-mq5-parity-departure]]).

## Рескью-доработки v2/v3 (2026-06-14) — риск-% сайзинг возвращает выживаемость

Пользователь: стратегия делалась под режим 2025–2026, универсальной быть не обязана, но «быть готовым ко всему» (вдруг режим сменится) — нужно. Цель улучшений: сохранить силу 2025–2026 И превратить годы-обнуляторы в малый убыток/флэт.

**v2 — регим-гейт по волатильности** (`UseVolRegime`: ATR_fast(14) > `AtrMaxMult`×ATR_slow(96) → не входить). **Отрицательный результат:** гейт фильтрует лишь 1–3% входов, годы-обнуляторы НЕ чинит (2018/19/22/23/24 по-прежнему в минусе, часть хуже), хороший режим не портит (2025/26 ≈ те же). Вывод: **убийственные сделки нельзя предсказать по волатильности на входе** (у Стейси нет эджа во входе) → правильный путь не «угадывать плохие сделки», а «ограничивать ущерб».

**v3 — риск-% сайзинг** (`RiskPercent`: лот от % equity на полный SL вместо фикс-лота). **Перелом:**
- макс. просадка **<10% во ВСЕ годы** (была 83–95% в годы-обнуляторы); обнулений нет;
- плохие годы — малый минус (−4…−8%), хорошие сохранили силу (2025 +67%, 2026 +124%/5.5мес);
- **непрерывно 2018→2026: +266% (×3.66), сквозная макс. просадка 23.25%, PF 1.27, 50326 сделок — переживает все режимы.**

Один параметр (сайзинг) — разница между «убийца счёта» (v1, обнуление 2019) и «выживает во всех режимах и растёт ×3.7» (v3). Цель «готовность ко всему» достигнута именно сайзингом, а не предсказанием режима.

> ⚠️ Метрика «точка безубытка винрейта» валидна только для фикс-лота; при риск-% $-размер сделки плавает с equity → мерить PF / return% / DD%.

**Дальше к идеалу:** срезать сквозную DD 23% и убыток плохих лет (equity circuit-breaker / HTF-фильтр на стрик 2022–24) + тюнинг риск-% (1%→2–3% за больший доход при контролируемой DD); затем мульти-ТФ ATR-относительные уровни + 99% тики Tickstory; затем интеграция в Aura.

Версии: `Aura/stacy-backtest/variants/` — **v1-base заморожен** (эталон), v2 (vol-gate), v3 (risk-%). Отчёты `v2_year_*` / `v3_year_*` / `v3_continuous_2018_2026`.

### v4 (ограничители ущерба) отвергнут; развёртка риск-%; продакшн = v3

**v4 = v3 + equity circuit-breaker + HTF-тренд-фильтр.** Нетто **хуже** v3: фильтры режут ~45% входов → чуть меньше убыток плохих лет, но **вдвое срезают прибыль хороших** (2020 −73%, 2025 −52%, 2026 −47%), DD не лучше. **Третье подтверждение:** у Стейси нет эджа во входе → любой фильтр входа (v2 ATR-гейт, v4 HTF+breaker) пропорционально уменьшает и хорошее, и плохое. Вывод: **единственный работающий рычаг — сайзинг, а не фильтры.**

**Развёртка риск-% (непрерывно 2018→2026, v3-движок; авторазвёртка через MT4 Optimization, `risksweep.set`):**
| Risk% | ×депо | Сквозная DD (отн.) | PF |
|---|---|---|---|
| 1.0% | ×3.7 | 23% | 1.27 |
| 1.5% | ×7.4 | 35% | 1.36 |
| 2.0% | ×13.8 | 45% | 1.48 |
| 2.5% | ×27.5 | 53% | 1.62 |
| 3.0% | ×50.7 | 62% | 1.78 |

Каждые +0.5% риска ≈ +10 пп просадки; доход сверхлинейно (компаунд). Рекомендация **1–2%** (1.5% — середина); 3% (DD 62%) частично возвращает риск обнуления на худших данных. Числа на 90%-модели/фикс-спреде оптимистичны, компаунд раздут мега-режимом 2025–26 — переносимая метрика риска это DD (отн.), не доход.

## Двухстадийный трейл v6 (2026-06-15) — калибровка трейла найдена

**Контекст.** Пользователь гонял pro-20 рядом с оригинальным `.obf` на живом счёте (одинаковые входы) и заметил: на одних и тех же сделках выходы разные — оригинал даёт сделке дышать и берёт больше, наш выскакивает у безубытка. Сначала ошибочно списал на фильтр входа — но входы идентичны, значит дело в ВЫХОДЕ.

**Развёртки трейла (зазор, старт, двухстадийный с высоким порогом) шли по одной кривой и оригинал не воспроизводили** — я ошибочно заключил «это фильтр входа, не трейл».

**Ключ дал пользователь (live-наблюдение):** оригинал переносит SL в безубыток **только при +$10 на 0.20 лота = +0.50 в цене** (наш — при +0.30). Тонкая развёртка вокруг 0.50 на v6 (двухстадийный трейл):

| BeTrigger | сделок | PF | винрейт | ср.выигрыш |
|---|---|---|---|---|
| ОРИГИНАЛ | 1384 | 2.37 | **97.9%** | 34.37 |
| 0.3 (старый наш) | 1678 | 2.55 | 98.5% | 26.74 |
| 0.4 | 1651 | 2.38 | 98.2% | 29.87 |
| **0.5** | 1637 | 2.19 | **97.9%** | 33.02 |
| 0.6 | 1618 | 1.96 | 97.5% | 35.54 |

**При `BeTrigger≈0.45–0.50` профиль совпадает с оригиналом** (винрейт 97.9% ровно, ср.выигрыш 33 vs 34, PF 2.2–2.4). Backtest подтвердил live-наблюдение.

**v6 = двухстадийный трейл:** (1) держать широкий стартовый SL (−25) до профита `BeTrigger`; (2) прыгнуть в безубыток (entry+`BeLock`); (3) тесный трейл `gap`/`step` 0.30. Старый одноступенчатый (`SL=Bid−0.30` от +0.30 профита) фиксировал безубыток слишком рано → шейкаут. Калибровка: **BeTrigger=0.50, BeLock=0.02, gap=step=0.30.**

**Поправка к прежним выводам:** разрыв среднего выигрыша (27 vs 34) — это **трейл (порог безубытка)**, а не фильтр входа (как я ошибочно заявлял ранее). Фильтр входа влияет вторично.

### v5 (ATR-относительные уровни) ОТВЕРГНУТ — стратегии нужен фикс. широкий стоп

Гипотеза: `SL = K×ATR(рабочий ТФ)` сделает стратегию ТФ-переносимой. Коэффициенты выведены из ATR(M30, 2025-26 ≈ $11.35): **SL=2.20×ATR, TP=0.53×ATR, trail=0.026×ATR** (на M30 воспроизводят $25/$6/$0.30). ATR по ТФ растёт по √времени (H4/M30 ≈ 2.9× при 8× времени). **Опровергнуто эмпирикой:**
- **По ТФ (2026):** PF просел почти везде vs v3-фикс (M30 2.07→1.75, M15 2.09→1.92, M5 1.78→1.49), H4 ушёл в убыток (1.14→0.88). Адаптив не спас ТФ.
- **По времени (непрерывно 2018→2026): КАТАСТРОФА** — net −6189 (vs v3 +26612), PF 0.86, просадка **98%** (почти ruin), 83.5k сделок.

**Инсайт:** эдж держится на **фиксированном относительно ШИРОКОМ стопе, который редко срабатывает** + трейл-в-безубыток. ATR-адаптив делает стоп тесным в спокойные периоды (2018, низкий ATR, золото ~$1300) → шум выбивает стопы пачками → near-ruin; фикс-$25 там был широк (~2% цены) и шум его не доставал. Третий случай (после v2/v4), где «улучшение» хуже — стратегия любит фикс. Моя рекомендация про ATR-относительность (по аналогии [[adr-004-impulse-adaptive-distance]]) **опровергнута данными**.

**Следствие для мульти-ТФ:** ATR-относительность для ЭТОЙ стратегии — неверный путь. **M30 — родной ТФ**; эдж слабеет вне (H4 PF 1.14, M5 cost-недостоверен). Если нужно переключение — только **пер-ТФ фикс-пресеты** (переоптимизировать фикс SL/TP/трейл под каждый ТФ), реалистичная полоса ~M15–H1. Продакшн остаётся v3 (фикс). v5 сохранён в `variants/` как отвергнутый.

|---|---|---|---|

Тесный SL → больший лот (риск-% сайзинг) → больше доход И просадка — **та же ось «доход⇄DD», что RiskPercent**. **Поправка к v5-выводу:** ФИКСИРОВАННЫЙ тесный стоп НЕ взрывается (только экстремальный SL=5 = 84% DD); взрывалась именно АДАПТИВНАЯ механика v5 (тесла стоп в спокойные периоды + ломала трейл). ## Продажная сборка (pro)

Из 20 параметров для покупателя оставлены **3**: `RiskPercent` (главный — аппетит к риску), `MaxSpreadPoints` (защита от широкого спреда, 0=off), `MagicNumber` (для нескольких ботов). Вся стратегия (сигнал/уровни/трейл/позиции) зашита `const` → покупатель не сломает + защита IP. **Две сборки по SL:** `stacybot-impuls-pro-25` (консервативная, ×3.7/DD23%) и `stacybot-impuls-pro-20` (чуть агрессивнее, ×6.1/DD26%). ## Внедрение в Aura (следующая фаза — заметки)

Ориентир — как делали AuraImpulse ([[adr-003-impulse-strategy-new-preset-type]]): вероятно **новый `strategy_type`** (напр. `stacytrend` / `auratrend`), т.к. сигнальная модель отличается и от AuraGrid, и от AuraImpulse. Что переиспользуется из существующего кода:
- Формула трейлинга — фактически та же, что у AuraImpulse (TZ_TRAIL_REWORK, [[adr-002-trail-rework-mq5-parity-departure]]).
- Паттерн «одна позиция + стартовый SL в том же order_send» — из AuraImpulse (анти-паттерн «SL отдельным тиком» уже отмечен там).
- Защита equity, lot_type, spread_buffer — заимствуемы.
Что новое:
- **Сигнал направления по `iMA`** (период/метод/цена как поля) — у Aura-стратегий индикаторов ещё не было.
- **Вход на закрытии бара рабочего ТФ** (а не по тикам/pending) — нужен bar-gate (как adaptive-distance в AuraImpulse считает по M1, здесь — решение раз на M30-бар).

## Open questions / что доводить

1. **Фильтр «качества» входа.** Оригинал входит ~на 24% реже нашей реконструкции — отсеивает слабые сетапы по критерию, **не извлечённому из офлайн-данных** (проверены и отвергнуты: расстояние от EMA, размер импульсной свечи, хедж). В `.mq4` есть выключенные `MinPrevBody`/`MinDistFromMA` для подгонки частоты. При внедрении в Aura — либо принять как есть, либо добить тиковыми данными тестера.
2. Точные `TrailStart`/`TrailGap`/безубыток-зазор (шаг 0.30 измерен, остальное — близко, доводится сверкой).
3. Magic / комментарий / slippage оригинала из отчёта не видны (в новом коде — свои).
4. Подтвердить скриншотом вкладки Inputs, что `Lots` — единственный параметр (косвенно подтверждено строкой Parameters отчёта).
