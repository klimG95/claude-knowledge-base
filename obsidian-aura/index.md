# Index — оглавление базы знаний

Это живое оглавление всей wiki. Обновляется агентом после каждой обработки `raw/` и любого значимого изменения в `wiki/`. Правила ведения — в [[AGENTS]].

Структура — три раздела ниже: **Темы** (крупные содержательные категории), **Сущности** (конкретные люди, проекты, продукты), **Источники** (книги, статьи, видео, исследования). Каждая запись — ссылка `[[имя-файла]]` плюс одна строка описания.
