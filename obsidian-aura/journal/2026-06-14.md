## StacyBot-Impuls — оценка качества подхода + проект-источник переведён в АРХИВ

Пользователь попросил как специалиста по алготрейдингу оценить качество торгового подхода Стейси и подтвердить, что всё необходимое перенесено в Aura (vault + память), после чего пометить `stacybot-recovery/` архивом.

### Оценка качества (новое — раньше в vault была только спецификация «что это», без вердикта «насколько хорошо»)
Разобрал отчёт Тестера оригинала (`StrategyTesterold.htm`). Ключевые выводы:
- **Отрицательная асимметрия (negative skew):** средний выигрыш +$34.37 против среднего проигрыша −$676.32 (**≈20:1 против**); TP 6.00 реально достигается лишь 6 раз из 1384 — почти весь профит от трейла.
- **98% винрейт — эффект ВЫХОДА, а не входа:** делается переносом SL в безубыток при первом плюсе; лонги/шорты выигрывают одинаково ~98% при почти случайном направлении «цена vs EMA(9)».
- **Точка безубытка по винрейту ≈ 95.2%** → запас всего ~2.7 пп над разорением. Конструкция хрупкая.
- **Что хорошо:** не скам — убыток ограничен жёстким стопом (~$750), нет мартингейла/сетки/прогрессии, выборка 1384 значима.
- **Риски, скрытые бэктестом:** окно 2.5 мес = один режим (нет шоков 2020/2022, макс. серия убытков = 2); 90% modelling + потиковый трейл завышают винрейт; микро-прибыль $34 уязвима к спреду/проскальзыванию/свопу за 24/7; фикс-лот = 7.5% депо на сделку.
- **Вердикт: 3/5 «рабочая, но хрупкая».** Условия доверия: walk-forward 3–5 лет, Monte-Carlo на перестановках, форвард-демо с плавающим спредом, риск-% сайзинг + spread/news-guard. **Импликация для Aura:** не продавать «98% винрейт» как фичу; навесить equity-защиту + риск-% lot_type + spread_buffer из существующего арсенала.

Полная аргументация занесена в [[stacybot-impuls-strategy]] (новый раздел «Оценка качества торгового подхода»).

## StacyBot-Impuls — backtest-harness построен, эмпирика OOS: стратегия как есть НЕ выживает

Пользователь решил улучшать стратегию и встраивать в Aura (новый strategy_type) с переключением ТФ. Обсудили направления: выбран фильтр режима (HTF×множитель + ADX); хеджирование отвергнуто (замок = отложенный убыток + двойной спред, полезное зерно уже забирает HTF-фильтр); усреднение/сетку на ту же позицию отвергли (превращает ограниченный убыток в неограниченный, удваивает negative skew, противоречит трендовому входу). Договорились: ATR-относительные уровни ради мульти-ТФ, валидация по каждому ТФ, тиковые данные Tickstory/Dukascopy для 99% (история M1 RoboForex уже глубокая — 2004→2026, для глубины Tickstory не нужен, только для качества тиков).

**Построен backtest-harness** (`Aura/stacy-backtest/`): изолированный portable-MT4 (build 1473, отдельно от рабочего терминала пользователя), компиляция через `metaeditor /compile`, headless-прогон через `terminal.exe smoke.ini /portable`. Ключевой баг конфига: ключи `[Tester]` должны иметь префикс `Test` (`TestExpert`/`TestSymbol`/…), иначе советник цепляется к живому графику вместо Тестера. Harness валидирован: окно апр–июн 2026 воспроизводит реконструкцию (1677 сделок, PF 2.58, DD 13.45%).

**Monte-Carlo (50k→20k перестановок списка сделок оригинала):** наблюдаемые 7.32% просадки — лестная случайность порядка; перестановка тех же сделок даёт медиану DD ~20%, 99-й перцентиль ~37%, худшую ~59% стартового капитала. Ранний кластер из 14 убытков обнуляет $10000. P(ruin)=0 при случайной перестановке, НО реальные убытки кластеризуются по режиму (что перестановка ломает) → реальный риск выше.

**Эмпирика OOS (главное):** непрерывный прогон 2018→2026 — **счёт $10000 обнулён за ~15 месяцев** (net −9994, DD 99.94%, PF 0.74). Разбивка по годам: **5 из 9 лет убыточны**; винрейт 90–98% во ВСЕ годы, включая обнуляющие счёт (2024: винрейт 94.7% при DD 94.7%) → винрейт бессмыслен как метрика. Не «тренд vs боковик» (2024 — аптренд, но почти blow-up): убивают всплески волатильности/резкие контр-движения кластерами. Убытки стабильно > номинала (−804…−1002 vs −750). Таблица и выводы — в [[stacybot-impuls-strategy]] (раздел «Эмпирическая проверка OOS»).

**Гейт Этапа 0 сработал:** стратегия как есть непригодна. Доработки (риск-% сайзинг + волатильно-новостной фильтр, затем HTF/ADX) = условие выживания, не косметика. Следующий шаг — Этап 1 (защита хвоста): риск-% сайзинг + волатильный/новостной фильтр, ретест по годам.

## StacyBot-Impuls — рескью-доработки v2/v3: риск-% сайзинг возвращает выживаемость

Пользователь уточнил позицию: стратегия под режим 2025–2026, универсальность не обязательна, но мерить продолжаем по всему диапазону лет — «быть готовым ко всему». Заморозил v1-base (`stacy-backtest/variants/`).

**v2 (регим-гейт по волатильности, ATR_fast>1.8×ATR_slow → спячка).** Отрицательный результат: гейт фильтрует 1–3% входов, годы-обнуляторы НЕ чинит, хороший режим не портит. **Урок: убийственные сделки нельзя предсказать по волатильности на входе** (нет эджа во входе) → ограничивать ущерб, а не угадывать.

**v3 (риск-% сайзинг, 1% equity на полный SL).** Перелом: макс. просадка <10% во ВСЕ годы (была 83–95%); плохие годы −4…−8%, хорошие сохранены (2025 +67%, 2026 +124%/5.5мес). **Непрерывно 2018→2026: +266% (×3.66), сквозная DD 23.25%, PF 1.27 — переживает все режимы.** Один параметр (сайзинг) = разница между обнулением (v1) и выживанием+ростом (v3). In-regime непрерывный базлайн фикс-лота (2025→июнь-2026): +108k (×10.9), но безубыток-винрейт 96.5% против 97.1% — тонко даже в лучшем режиме; MC при фикс-лоте даёт медиану reorder-DD 49% → подтверждает необходимость риск-%.

Технически: harness через `terminal.exe <ini> /portable` (ключи `[Tester]` с префиксом `Test`); компиляция вариантов `metaeditor /compile`; песочница блокирует `Remove-Item` рядом с путём `C:\Program Files` — полагаться на `TestReplaceReport=true`. Парсер «точка безубытка винрейта» валиден только для фикс-лота.

**Дальше к идеалу:** circuit-breaker / HTF-фильтр на стрик 2022–24 + тюнинг риск-% (1→2–3%); мульти-ТФ ATR-относительные уровни; 99% тики Tickstory; интеграция в Aura. Детали и таблицы — в [[stacybot-impuls-strategy]] (раздел «Рескью-доработки v2/v3»).

**v4 (circuit-breaker + HTF-фильтр) отвергнут.** Нетто хуже v3: фильтры режут ~45% входов → вдвое срезают прибыль хороших лет (2020 −73%, 2025 −52%) при минимальной пользе на плохих. Третье подтверждение: нет эджа во входе → фильтры пропорционально уменьшают всё. **Единственный работающий рычаг — сайзинг.** Развёртка риск-% (непрерывно 2018→2026): 1%→+266%/DD23%, 2%→+1283%/DD45%, 3%→+4971%/DD62% (рекомендую 1–2%; 3% возвращает риск обнуления). **Продакшн = v3, `RiskPercent` — настраиваемый input** (пользователь валидирует аппетит сам: Тестер Inputs / Optimization-развёртка — реализация ≈ нулевая, параметр уже есть). Все версии в `variants/`.
