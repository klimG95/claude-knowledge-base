## Метод — доказательная диагностика по живым логам (не гадание)

Сразу зафиксировал: strip `.py`→`.pyc` (Фаза 2) не может менять торговую логику (pyc ≡ скомпилированный py). Симптомы — торговые, значит код. Дальше — логи и git blame:

1. Свежие логи есть (бот гонялся 31.05–04.06). Magic-диры: `20260001`=Grid, `20260002`=Impulse. **Grid здоров** (`profit_trail_sl_set`, `channel_reset_after_close`, `ingest_ok`) → баги только в Impulse.
2. Частоты Impulse: `impulse_pending_modify_failed` 3261, `trade_retries_exhausted` 3261. **Retcode: 10018 (market closed) ×9783**, 10016 ×2, 10029 ×3. `poll_heartbeat` p99 253-333мс (петля замирала).
3. **git blame решающий:** `impulse.py`/`executor.py`/`validation.py` НЕ менялись после checkpoint `461904b` (только rebrand-нейминг). → защита и perf-рефакторинг **невиновны**; баги латентные в Impulse, проявились на волатильном XAU у DooTechnology. Откат не помог бы — нужны точечные фиксы.

## Фиксы (коммит `62694f3`, PR #36)

- **Bug B (доминанта):** `MARKET_CLOSED` (10018) убран из `executor._RETRYABLE`. Был → ретрай 3×0.2с на закрытом рынке = 0.6с заморозки loop ×9783 (дневной перерыв сессии XAU). Это «окно не отвечает / кнопка не закрывает / хаос». `NO_PRICES` остаётся retryable.
- **Bug A:** initial SL 10016 «Invalid stops» (дистанция от текущей цены в freeze-level). Позиция защищена pre-fill SL (шире), но state писался в проваленное значение → trail от несуществующего уровня. Fix: state = фактический брокерский SL.
- **Bug C:** сервер отвергал telemetry `mode="IMPULSE"` (Literal SCALP/CG + колонка String(5)) → вся Impulse-телеметрия дропалась. Fix: ModeName+=IMPULSE, String(16), миграция 0007.
- **Регрессия моей Фазы 6:** `tests/integration/conftest.py` JWT-ключ <32 валил 11 integration + 12 admin_bot. Пропустил, т.к. после Фазы 6 гонял только server-набор. Урок зафиксирован.

Verify: bot **1328 passed**, server **237 passed**, 0 fail/err. 3 новых теста.
